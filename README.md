# LLM Security Red Team
 
Research and hands-on testing of LLM security risks: hallucinations, prompt injection (direct & indirect), data exfiltration, jailbreaking, model bias, and defensive mitigations (guardrails, output validation, content classification, governance).
 
- **`llm-security-notes.md`** — reference notes covering each risk category: mechanism, exploitation techniques, and mitigations.
- **`redteam-capstone-findings.md`** — a red-team exercise against a hardened system prompt, testing system prompt extraction, role override, jailbreak, and scope escape, with severity ratings and root-cause analysis.
**Result:** 1 of 4 tested attack vectors succeeded (system prompt extraction) against the hardened prompt.
 
For defensive/awareness purposes only.
